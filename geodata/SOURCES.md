# Источники геоданных

`cities-geo.tsv` — координаты и атрибуты всех городов словаря. Из него `lps-geo` собирает `geo-N.bin`:

```
go run ./cmd/lps-geo -dict testdata/dict/data-81.db2 -cities geodata/cities-geo.tsv -out testdata/dict/geo-81.bin
```

## Первичное заполнение (словарь v81, ноябрь 2026)

| `source` | Строк | Откуда |
|---|---|---|
| `geonames` | 17 644 | GeoNames `allCountries` и `alternateNamesV2`, дамп от 8 ноября 2026 |
| `wikidata` | 2 917 | Wikidata: точный русский label, населённый пункт (P31/P279* Q486972), страна по ISO |
| `web` | 955 | статьи Wikipedia и другие страницы с координатами; адрес в колонке `url` |

- Атрибуты (`iso`, `population`, `feature`, `admin1`, `timezone`, `name_en`) взяты из GeoNames и заполнены только у строк с `geonameid`.
- Как сопоставлялись города:
  - GeoNames — по точному русскому названию в странах, которые соответствуют id страны словаря;
  - остаток — Wikidata;
  - всё, что осталось, — агенты по статьям, с выборочной перепроверкой.
- Каждая строка прошла обратное геокодирование: ближайший населённый пункт GeoNames `cities500` лежит в одной из стран, соответствующих её id.

## Подложка карты

`world.bin` в клиенте собран один раз из Natural Earth 1:110m land (v5.1.2). Обработка:

- контуры упрощены алгоритмом Дугласа — Пекера с допуском 0,1°;
- кольца площадью меньше 0,5 кв. градуса отброшены.
