Удаление данных пользователя

Чтобы удалить все данные вашего аккаунта в приложении «Сыграем в Города», отправьте письмо на quandastudio@mail.ru с темой «Удаление данных».

В письме укажите имя игрока и способ входа (Google, ВКонтакте или Одноклассники). По вашему запросу мы удалим аккаунт, друзей, историю игр и аватар.

Подробнее о хранимых данных — в Политике конфиденциальности.
